# Keynote and Google Slides

*Chapter in progress.* The [slides chapter](slides.md) is written for PowerPoint. Decks made in Keynote or Google Slides come to PowerPoint for remediation; this chapter covers what changes for each. Decks written in LaTeX need a different route: see [Beamer](beamer.md).

## Keynote

*Section planned.* In short: export the deck to PowerPoint (.pptx), remediate there, and export the PDF from PowerPoint; Keynote's own PDF export failed our audit. Fixes that change how a slide looks (text instead of a screenshot of code, contrast) are best carried back to the Keynote file so they are not redone each year. See [Slides](slides.md).

## Google Slides

*Section planned.* Google Slides can download a deck as .pptx, which then goes through the slides pipeline. We have not tested what survives the download.
