# Changelog

This file records changes from the first formal release (version 0.1) onward.

Until then, the repository is a draft shared for review. Rule numbers (P1, F1, E1, …), file names, and the organization of the guide are preliminary and may change without being recorded here.

From the first formal release, rule numbers are fixed: a rule that is dropped keeps its number, listed under *Retired IDs* in its chapter, and no number is reused. Each release's changes, including any retired rules, will be listed below.
