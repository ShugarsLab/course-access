# Test kits

Small kits for checking how screen readers handle course materials, to run on your own setup. What we have found so far, with these kits and otherwise, is in [Test results](../README.md).

## Long files in RStudio (`rstudio-long-files/`)

A screen reader has been observed to stop reading partway through a long file in RStudio's editor. These files test where, and whether the limit counts lines or characters. **Status:** partly tested. See [its README](rstudio-long-files/README.md). How to send results: [Contributing](../../CONTRIBUTING.md#share-test-kit-results).
